Circuit installs as a plugin in your coding agent. Pick your tool below.

## Claude Code

Run these in Claude Code:

```text
/plugin marketplace add petekp/circuit
/plugin install circuit@circuit
/reload-plugins
```

## Codex

Run this in your shell:

```bash
codex plugin marketplace add petekp/circuit --ref circuit--v0.1.0-alpha.6
```

## Run your first task

Once Circuit is installed, start every task the same way:

```text
/circuit:run <your task>
```

Circuit reads the task and routes it to the flow that fits: Build, Fix, Review,
Explore, Prototype, or Pursue. You do not have to pick the flow yourself.

See [Flows](/docs/flows) for what each one does.
