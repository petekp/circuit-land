---
title: Pursue
description: Coordinate several changes toward one objective.
---

Pursue drives a durable objective across steps: turn one or more ideas into a
pursuit contract, coordinate their order into waves, run the changes serially,
verify, review the coordination, and close with evidence.

## When to use

- A durable objective made of one or more ideas.
- Several related changes you want sequenced rather than run blind.
- Work where one change could interfere with another and needs review.

## What it does

<Mermaid
  label="Pursue stages, in order"
  chart={`

  Frame --> Coordinate --> Execute --> Verify --> Review --> Close
`}
/>

Pursue runs six stages, carrying each report forward to the next:

- **Frame** — turns the ideas into a pursuit contract: the objective, the
  pursuits, and candidate verification commands.
- **Coordinate** — builds a pursuit graph (dependencies, serial groups, and
  read-only groups that can run in parallel), then orders the pursuits into
  execution waves.
- **Execute** — relays the work to a worker and runs the code-changing pursuits
  serially, never writing in parallel.
- **Verify** — runs the proof commands and records exit status and output.
- **Review** — relays the result to a separate worker to check the coordination
  across the changes.
- **Close** — writes the Pursue result file with the outcome, the chain of
  [evidence](/docs/concepts/evidence-and-runs), and residual risks.

Pursue has no [checkpoints](/docs/concepts/checkpoints).

## Example

```text
/circuit:run tidy the logging and add request ids
```

```bash
circuit run pursue --goal 'tidy the logging and add request ids'
```
